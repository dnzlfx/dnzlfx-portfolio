How I build

Agents that run on your own machine

My work starts from a simple constraint: the model, the data and the execution environment should belong to whoever runs them. That means local inference, explicit safety policies, role-based access control and SSH automation over my own Linux nodes — auditable and deterministic instead of opaque.

Python TypeScript SSH automation RBAC & audit logs

Retrieval that can prove itself

A language model is only useful when its claims can be traced. In the systems I ship, hybrid retrieval combines dense embeddings with BM25 and every generated statement has to survive a citation check against the source document before a person ever reads it.

FastAPI Hybrid RAG (dense + BM25) Vision & audio streams React + Vite

Care for the architecture and for the surface

Data structures, module boundaries and error handling decide whether a system survives its second year. Typography, motion and contrast decide whether anyone wants to use it. I treat both as the same job — and this page is part of that claim: native HTML, CSS and JavaScript, no framework, no build step, scroll-linked transforms driven by requestAnimationFrame and CSS custom properties.
